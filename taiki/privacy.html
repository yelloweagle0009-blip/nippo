待機アラーム プライバシーポリシー

制定日：2026年11月23日　／　提供者：supercode1031

「待機アラーム」（以下「本アプリ」）は、並んで待っているときに、スマートフォンのカメラで前の車を見て、前の車が動いたら音で知らせるアプリです。本アプリでの情報の扱いを次のとおり定めます。

1. 集める情報

本アプリは、氏名・メールアドレス・電話番号・位置情報・連絡先など、個人を特定できる情報を集めません。アカウントの登録もありません。

2. カメラの映像

  • カメラの映像は、前の車が動いたかを判断するためだけに、スマートフォンの中で処理します。
  • 映像を保存したり、インターネットへ送ったりすることはありません。

3. スマートフォンの中に保存する情報

  • 「知らせるタイミング」などの設定と、初めての説明を見たかどうかを、スマートフォンの中に保存します。外へ送ることはありません。
  • 利用者が「鳴る前の記録を保存」を押したときだけ、鳴る前の約30秒分の小さな白黒の画像と判断の数値を、スマートフォンの「ダウンロード」フォルダにファイルとして保存します。このファイルを誰かに送るかどうかは、利用者が決めます。

4. インターネットの利用

本アプリは、画面を表示するためのページを GitHub Pages（GitHub, Inc. のサービス）から読み込みます。このとき、通常のウェブサイトと同じように、GitHub のサーバーには接続元の IP アドレスなどが記録されることがあります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

5. 第三者への提供

本アプリが利用者の情報を第三者に提供することはありません。

6. 変更

本ポリシーを変更するときは、このページでお知らせします。広告などを入れる場合は、その前にこのページを改めます。
